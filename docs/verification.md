## 확인 범위와 한계

- 위 결과는 직접 확인한 화면과 조작 범위에 대한 기록이며, 모든 브라우저와 기기의 동작을 보장하지 않습니다.
- Vue 실습 사이트의 초기 화면은 확인했지만 TMDB 영화 목록과 검색은 API 키가 없어 재검증하지 못했습니다.
- Windows 로컬 빌드는 아직 검증하지 않았습니다.
- 최종 제출 전 최신 배포를 기준으로 주요 기능을 다시 확인하고 검사 날짜와 증거 자료를 보완합니다.
